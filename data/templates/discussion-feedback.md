### 1.2 每个标签的判断口径（一句话即可；默认值见右侧，可直接改）

| 标签 | 我们的口径（【填写】，留空 = 用默认） | 默认口径 |
|------|------|------|
| 重要 = 是 | | 影响核心流程或数据正确性；或上个月 ≥3 个不同客户提出；或安全/合规；或合同承诺；或战略客户有明确流失风险 |
| 紧急 = 是 | | 影响正在发生（故障、数据、安全、集成中断且无替代），或硬性截止日在 30 天内；客户自己写“很急”不算 |
| 迭代 | | 真实能力缺口且通用或重要；必须修复的缺陷 |
| 拒绝 | | 已支持（给用法）/ 超出定位 / 单客户定制（给替代）/ 违背安全合规或多租户原则 / 技术不可行 |
| 待评估 | | 价值高但难度大需技术评估；信息不足需澄清；多诉求需拆分 |
| P0 / P1 / P2（选 B 时） | | P0=重要且紧急，P1=重要不紧急，P2=其它 |
