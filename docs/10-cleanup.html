10清理资源 A/B 通用

实验结束后删除你创建的所有资源，避免产生费用。脚本只删除带你个人前缀 s12lab-zhang3- / s12lab_zhang3_ 的资源，不会影响同组其他人。

想保留 Demo 素材？先截好对比页、分诊报告和控制台的图，或把 results/ 下的文件下载下来，再清理。
10.1

运行清理脚本

5 分钟

删除在线评估、评估器、Lambda、Runtime、S3 桶、日志组和 IAM 角色等本实验资源。

先预览会删什么（不会真正删除）：

./99-cleanup.sh --dry-run

确认无误后执行：

./99-cleanup.sh

脚本：99-cleanup.sh → labkit/cleanup.py（按依赖顺序删除：在线评估 → 评估器 → Lambda → Runtime → S3 → 日志组 → IAM 角色；可重复运行）

预期输出（节选）： 
▶ 清理范围：我的资源 s12lab-zhang3-* · 区域 us-west-2
  🗑  停用在线评估 s12lab_zhang3_online_b
  🗑  删除在线评估 s12lab_zhang3_online_b
  🗑  删除评估器 s12lab_zhang3_label_accuracy
  ...
  🗑  删除 Lambda s12lab-zhang3-eval-label
  🗑  删除 Lambda s12lab-zhang3-eval-reject
  🗑  删除 Runtime s12lab_zhang3_agent (s12lab_zhang3_agent-AbCdEf1234)
  🗑  清空并删除 S3 桶 s12lab-zhang3-<account>-us-west-2
  🗑  删除日志组 /aws/bedrock-agentcore/s12lab-zhang3-local-agent
  🗑  删除日志组 /aws/lambda/s12lab-zhang3-eval-label
  ...
  🗑  删除 IAM 角色 s12lab-zhang3-runtime-role
  🗑  删除 IAM 角色 s12lab-zhang3-eval-lambda-role
  🗑  删除 IAM 角色 s12lab-zhang3-online-eval-role
10.2

确认没有残留资源

2 分钟

脚本逐项列出，确认带实验前缀的资源都已删除。

清理脚本最后会自动检查一遍；之后想再查一次：

./99-cleanup.sh --verify-only
预期输出： 
▶ 残留检查（us-west-2，前缀 s12lab_zhang3_* / s12lab-zhang3-*）
  ✅ 在线评估配置: 0
  ✅ 自定义评估器: 0
  ✅ AgentCore Runtime: 0
  ✅ Lambda 函数: 0
  ✅ S3 桶: 0
  ✅ IAM 角色: 0
  ✅ 日志组: 0
  ❌ EC2 堆栈: 1 ['s12lab-ec2-zhang3']
❌ 仍有 1 个资源（删除中的 Runtime/堆栈可稍后重查）
此时只剩 EC2 堆栈 1 个是正常的：你正在用这台 EC2，下一步才删除它。Runtime 删除需要 1–2 分钟，偶尔第一次检查还能看到它，稍后再查即可。
10.3

删除 EC2 堆栈

3 分钟

最后删除 CloudFormation 堆栈（EC2 本身）。删除后 EC2 上的所有文件都会消失。

方式一：控制台

  1. CloudFormation 控制台（区域与实验一致）→ 堆栈 → 选中 s12lab-ec2-zhang3。
  2. 点 删除 → 确认 删除，等待状态变为 DELETE_COMPLETE（约 2–3 分钟）。

方式二：CloudShell（把 zhang3 换成你的后缀）：

aws cloudformation delete-stack --stack-name s12lab-ec2-zhang3
aws cloudformation wait stack-delete-complete --stack-name s12lab-ec2-zhang3 && echo "✅ 已删除"
预期输出： 
✅ 已删除
讲师专用（全组结束后）：在讲师自己的电脑上（仓库已 clone、config/local.env 里设置了 AWS_PROFILE；不要在某台实验 EC2 上运行，它会把自己也删掉），删除本账号本区域所有人的 s12lab 资源（含所有 EC2 堆栈），并恢复账号级设置（关闭 Transaction Search、删除 aws/spans 日志组）： 
./99-cleanup.sh --all --dry-run
./99-cleanup.sh --all --account-level
--account-level 会影响整个账号的 trace 设置，只在确认所有人都结束后执行。
