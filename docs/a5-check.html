用检查脚本读取 CloudWatch 里的数据，判断是否满足 AgentCore Evaluations 的要求；差距大时直接切换到 B 版。

3 分钟

./12-A-check-telemetry.sh

A5.2

读懂检查结果：通过 / 有缺口 / 差距大

3 分钟

按结果决定：继续评估、补埋点，还是换 B 版。

结论含义下一步
通过session、trace、Agent 输入输出、三项标签都能读到继续 第 6 章 注册评估器
有缺口 🟨必需项都满足，缺“可选”项（例如没有工具调用 span、没有 token 用量）可以继续评估（标签准确率、话术质量不受影响）；有时间再补埋点
有缺口 🟧只缺 1 项必需内容按 ❌ 项补埋点后重试（A3.4）；10 分钟内补不上就切换到 B 版
差距大 🟥缺多项必需内容：找不到 session / 没有 Agent 输出 / 不是受支持框架的埋点格式，评估器无法打分不在现场硬改客户 Agent → A5.3 切换到 B 版
“找不到 session”最常见的原因是数据还没到：等 2–3 分钟再查；其次是没开 Transaction Search（1.8）。
A5.3

差距大时：切换到 B 版

1 分钟

不在现场硬改客户 Agent，改用我们准备好的 mock agent 完成评估闭环。

  1. 页面右上角“我的路线”点 B 版 mock agent。
  2. 从 B3 部署 V0 到 AgentCore Runtime 继续。第 1–2 章做过的环境、数据和黄金集都照常使用。
