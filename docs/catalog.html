原则

平台定位与原则

  1. 通用性优先：上个月 ≥3 个不同客户提出，或属于多数行业客户都会用到的能力缺口，才算通用需求。
  2. 配置优先于开发：已有能力能满足的，给出用法而不是新开发。
  3. 单客户深度定制通过自定义组件、自定义函数、开放 API 或伙伴实施解决，不进平台迭代。
  4. 安全、合规、多租户隔离与平台稳定性是红线，不可为单个客户让步。
  5. 数据丢失、安全漏洞、合规与合同承诺类反馈不可自动拒绝。
