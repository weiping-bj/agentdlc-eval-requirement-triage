Agent 的输入与输出

一条需求反馈进来，Agent 输出一个固定结构的判断结果；评估器就按这个结构打分。

字段取值说明
important 是否重要是否影响面、客户价值、是否通用
urgent 是否紧急是否是否阻断业务、有无替代方案、是否有时间节点
decision 处理建议迭代拒绝待评估拒绝时必须给出拒绝理由和对客户的话术
level 优先级（可选）P0P1P2预留字段：现场如果决定用分级代替“是/否”，直接启用（见 讨论 D.3）
reasoning / reject_reason / customer_reply文本判断依据 / 专业拒绝理由 / 对客户的沟通话术
完整输出格式见输出结构定义文件（M2 补链接到 agent 代码中的 schema）
